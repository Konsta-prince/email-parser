# 📧 Email Parser — Парсер почты в Excel

Автоматический сбор писем из почтового ящика по ключевым словам с сохранением результатов в удобную таблицу Excel.

## 🚀 Возможности

-  Поиск писем за заданный период (например, за последние 30 дней)
- 🎯 Фильтрация по ключевым словам (в теме и теле письма)
- 📊 Сохранение результатов в Excel с автоформатированием столбцов
- 📎 Определение наличия вложений
- 🔒 Безопасное хранение пароля в локальном файле `config.json`
- 💾 Работает как обычный `.py` скрипт или как готовый `.exe` файл

## 📋 Что сохраняется в Excel

| Столбец | Описание |
|---------|----------|
| Дата | Дата и время получения письма |
| Email отправителя | Адрес отправителя |
| Тема | Тема письма |
| Тело письма | Первые 500 символов текста |
| Вложения | Да/Нет |
| Ключевые слова | Найденные совпадения |

## ⚙️ Установка и запуск

Вариант 1: Запуск через Python:

1. Установите Python 3.10+
2. Установите зависимости:
   ```bash
   pip install openpyxl

Вариант 2: Запуск через .exe файл:

Просто запустите search.exe двойным кликом. Никаких дополнительных установок не требуется.
🛠 Настройка
Перед запуском отредактируйте файл config.json:
{
  "email_settings": {
    "imap_server": "imap.yandex.ru",
    "email_address": "ваш_email@yandex.ru",
    "password": "ваш_пароль_или_пароль_приложения"
  },
  "search_settings": {
    "days_to_search": 30,
    "keywords": ["заказ", "счет", "чертеж"]
  }
}

Поддерживаемые почтовые серверы:
Яндекс: imap.yandex.ru
Mail.ru: imap.mail.ru
Gmail: imap.gmail.com (требуется пароль приложения)

⚠️ Важно: Для Gmail и Яндекса рекомендуется использовать "Пароль приложения" вместо основного пароля от аккаунта.
